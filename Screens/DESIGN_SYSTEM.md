# Relay Design System

## Overview
- **Color Mode:** Dark
- **Primary Color:** `#38bdf8` / `#8ed5ff`
- **Background / Surface:** `#0b1326`
- **Surface Tiers:** `#060e20` (Lowest) -> `#131b2e` (Low) -> `#171f33` (Container) -> `#222a3d` (High) -> `#2d3449` (Highest)
- **Typography:** Hanken Grotesk (Display, Headline, Body, Label)
- **Base Grid:** 4px unit
- **Corner Radius:** 4px (`ROUND_FOUR` / `0.25rem`)
